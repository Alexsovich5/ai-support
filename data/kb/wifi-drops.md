# Wireless network drops

Laptops that lose the wireless network in some rooms are often roaming between access points or using an old driver.

1. Forget the wireless network and join it again.
2. Update the wireless adapter driver from the software portal.
3. Note the room and time whenever the signal is lost.
4. Try a wired port to rule out a fault in the laptop.
5. Report rooms with weak signal so the access points can be checked.
