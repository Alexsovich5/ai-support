# Printer shows offline

A printer listed as offline cannot receive print jobs from the workstation.

1. Check that the printer is powered on and shows no error on its panel.
2. Open the print queue, cancel stuck jobs and clear "Use printer offline".
3. Remove the printer and add it again from the print server list.
4. Restart the Print Spooler service.
5. If other people on the floor cannot print either, report the printer name and location.
